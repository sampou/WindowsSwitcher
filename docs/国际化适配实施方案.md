# 国际化适配实施方案

## 目标

支持简体中文和英文。默认读取 macOS 系统首选语言；未匹配或翻译缺失时回退为简体中文。设置页提供“跟随系统 / 简体中文 / English”的应用内语言选择，不修改 macOS 全局语言。

## 覆盖范围

- 设置页、切换器、搜索与空状态
- 窗口布局面板、状态栏菜单、快捷键相关提示
- 更新、权限、辅助功能标签与帮助文本
- 系统权限说明

日志、错误码、窗口标题、应用名称、Bundle ID 和系统原始返回文本不翻译。

## 技术方案

- 使用 Localizable.strings 保存界面键值，使用 InfoPlist.strings 保存隐私权限说明。
- 使用 L10n 统一处理 AppKit 的运行时文本；SwiftUI 设置页注入所选 Locale，语言切换即时生效。
- 所有可持久化和路由用途的动作标识保持不变，只本地化展示标题。
- Xcode target 显式打包两个 lproj 资源目录，发布前检查 app 包内资源。

## 验收

1. 简体中文环境维持既有文案和交互。
2. 可在设置页手动选择跟随系统、简体中文或英文，且选择跨重启保留。
3. 英文环境下菜单、窗口布局标题、搜索和主要设置项不残留中文。
4. 窗口切换、全局快捷键和窗口布局执行逻辑不因语言切换改变。
5. DMG 安装后的 app 包内同时包含 en.lproj 与 zh-Hans.lproj。
