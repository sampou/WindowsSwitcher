# 版本更新历史

本文档记录 WindowsSwitcher 的所有版本更新内容。

---

## v0.0.143
**发布日期**: 2026-05-12

### 修复问题

- 修复短按 Tab 键时意外触发连续切换的问题
- 移除长按快速切换功能（由于 Carbon 热键 API 限制，无法检测 Tab 键释放）

### 功能调整

- 状态栏图标左键点击现在显示设置界面（而非切换器面板）
- 面板选中窗口超出可视范围时自动滚动居中显示

---

## v0.0.125
**发布日期**: 2026-05-10

### 优化改进

#### DMG 安装包样式优化
- 优化 DMG 安装界面布局
- 应用图标（128px）在左侧，Applications 文件夹在右侧
- 添加箭头指示和装饰圆点
- 底部添加安装提示文字
- 使用 `create-dmg` 工具创建专业的安装体验

#### 面板交互修复
- 修复面板显示后无法响应键盘事件的问题（ESC、方向键等）
- 修复窗口关闭按钮无响应的问题
- 确保面板正确接收鼠标事件

#### 窗口排序持久化
- 实现窗口活动时间持久化存储
- 程序重启后窗口排序与关闭前一致
- 自动清理超过 30 天的活动记录

---

## v0.0.76
**发布日期**: 2026-04-26

### 新增功能

#### 版本更新检查
- 启动时自动检查是否有新版本
- 发现新版本时弹出更新提示窗口，显示：
- 应用图标和最新版本号
- Release Notes 更新内容
- 自动检查更新选项（仅当未开启时显示）

#### 下载更新功能
- 内置下载器，无需打开浏览器
- 显示下载进度条和速度
- 支持断点续传（网络中断后可继续）
- 下载完成自动弹出安装界面
- 临时文件自动清理

---

## v0.0.75
**发布日期**: 2026-04-26

### 优化改进
- 在窗口切换时实时刷新预览，确保显示最新内容
- 添加延迟检查机制防止修饰键假释放误关闭面板
- 并行加载预览提升性能
- 简化窗口激活逻辑，减少不必要的缓存刷新

## v0.0.70
**发布日期**: 2026-04-25

### 功能特性

#### 窗口快速切换
- 使用 `Option + Tab` 快捷键呼出窗口切换面板
- 显示所有打开窗口的实时预览缩略图
- 支持按最近使用时间排序，快速找到目标窗口

#### 同应用窗口切换
- 使用 `Option + \`` (反引号) 快速切换同一应用的多个窗口
- 支持反向切换 `Option + Shift + \``

#### 程序坞窗口预览
- 悬停程序坞图标时自动显示该应用的窗口预览
- 悬停预览项时显示大尺寸实时预览
- 无需点击即可快速预览窗口内容

#### 快捷键自定义
- 所有快捷键均可自定义配置
- 支持修改窗口切换、同应用切换的快捷键
- 实时预览快捷键设置效果

#### 主题定制
- 支持浅色、深色、自动跟随系统主题
- 多种界面主题可选
- 完美适配 macOS 系统外观

#### 智能布局
- 面板尺寸根据窗口数量自适应
- 预览窗口尺寸与实际窗口一致
- 支持多屏幕和不同分辨率
