# 版本更新历史

本文档记录 WindowsSwitcher 的所有版本更新内容。

---

## 未发布

### 功能说明

- 中英文 README 与用户手册统一当前功能：搜索输入框已下线，已支持快捷键自定义、程序坞预览和窗口布局。
- 区分全新安装的 Option 默认快捷键与升级保留的用户配置；旧版本记录中的行为仅描述对应历史版本。

### 切换正确性

- 激活前重新检查窗口 ID、进程和应用身份，拒绝已消失或被复用的目标；松开修饰键前协调同应用会话的已关闭窗口。
- 修正非零屏幕原点下的面板居中，切换面板加入多桌面和全屏辅助窗口行为。
- 按已成功注册的组合键接管对应系统快捷键；Option 默认配置保留系统 Command 切换。

### 响应与常驻开销

- 面板关闭或列表刷新时取消过期截图任务；排队截图可立即取消，旧结果不能重新回填已移除的窗口。
- 后台每 15 秒至多预热 12 个近期窗口缩略图和 2 个背景大图；面板内仍加载全部窗口，缩略图使用 nominal 分辨率截图。
- 新增只读 CPU/RSS 与面板创建耗时采样工具；面板创建耗时不代表完整按键响应延迟。

### 首次使用与更新

- 移除启动时的空白主窗口；首次使用或权限缺失时显示设置，已有授权时后台启动。
- 通用设置显示实际权限状态和恢复入口；授权变更通知会恢复系统监听，重复恢复先清理旧监听。
- 手动更新检查始终可用，进行中禁用重复请求，支持失败后重试，并在无更新时明确显示结果。
- 修正屏幕预览缓存和更新联网说明，并补齐中英文本地化。

## v0.0.187
**发布日期**: 2026-09-06

### 功能调整

- 暂时下线窗口切换面板的搜索输入框；`Option + Tab`、状态栏“显示切换器”和同应用切换均直接进入窗口切换体验。
- 移除应用名称、窗口标题和 Bundle Identifier 搜索的用户可见入口与产品说明，避免功能预期与当前实际价值不一致。
- 保留底层 `FilterEngine`，不删除已有筛选实现，待重新确认使用场景后可恢复或按新方案改造。

### 界面与质量

- 面板顶部区域改为窗口布局工具栏，维持现有窗口布局入口和面板尺寸计算。
- 新增回归约束：切换面板不得挂载 `SearchBarView`，确保搜索功能在暂缓期间不会被意外重新暴露。

## v0.0.143
**发布日期**: 2026-05-12

### 修复问题

- 修复短按 Tab 键时意外触发连续切换的问题
- 移除长按快速切换功能（由于 Carbon 热键 API 限制，无法检测 Tab 键释放）

### 功能调整

- 状态栏图标左键点击现在显示设置界面（而非切换器面板）
- 面板选中窗口超出可视范围时自动滚动居中显示

## v0.0.125
**发布日期**: 2026-05-10

### 优化改进

#### DMG 安装包样式优化
- 优化 DMG 安装界面布局
- 应用图标（128px）在左侧，Applications 文件夹在右侧
- 添加箭头指示和装饰圆点
- 底部添加安装提示文字
- 使用 `create-dmg` 工具创建专业的安装体验

#### 面板交互修复
- 修复面板显示后无法响应键盘事件的问题（ESC、方向键等）
- 修复窗口关闭按钮无响应的问题
- 确保面板正确接收鼠标事件

#### 窗口排序持久化
- 实现窗口活动时间持久化存储
- 程序重启后窗口排序与关闭前一致
- 自动清理超过 30 天的活动记录

## v0.0.76
**发布日期**: 2026-04-26

### 新增功能

#### 版本更新检查
- 启动时自动检查是否有新版本
- 发现新版本时弹出更新提示窗口，显示：
- 应用图标和最新版本号
- Release Notes 更新内容
- 自动检查更新选项（仅当未开启时显示）

#### 下载更新功能
- 内置下载器，无需打开浏览器
- 显示下载进度条和速度
- 支持断点续传（网络中断后可继续）
- 下载完成自动弹出安装界面
- 临时文件自动清理

## v0.0.70
**发布日期**: 2026-04-25

### 功能特性

#### 窗口快速切换
- 使用 `Option + Tab` 快捷键呼出窗口切换面板
- 显示所有打开窗口的实时预览缩略图
- 支持按最近使用时间排序，快速找到目标窗口

#### 同应用窗口切换
- 使用 `Option + \`` (反引号) 快速切换同一应用的多个窗口
- 支持反向切换 `Option + Shift + \``

#### 程序坞窗口预览
- 悬停程序坞图标时自动显示该应用的窗口预览
- 悬停预览项时显示大尺寸实时预览
- 无需点击即可快速预览窗口内容

#### 快捷键自定义
- 所有快捷键均可自定义配置
- 支持修改窗口切换、同应用切换的快捷键
- 实时预览快捷键设置效果

#### 主题定制
- 支持浅色、深色、自动跟随系统主题
- 多种界面主题可选
- 完美适配 macOS 系统外观

#### 智能布局
- 面板尺寸根据窗口数量自适应
- 预览窗口尺寸与实际窗口一致
- 支持多屏幕和不同分辨率
