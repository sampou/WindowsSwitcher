A macOS window switching enhancement tool that brings a Windows‑style window switching experience to your Mac.

## ✨ Features

### 🔄 Quick Window Switching
- Press `Option + Tab` to bring up the window switching panel
- Shows live preview thumbnails of all open windows
- Sorted by most recently used to quickly find the target window

### 🔂 Switch Between Windows of the Same App
- Press `Option + `` ` (backtick) to quickly switch between multiple windows of the same app
- Supports reverse switching with `Option + Shift + `` `

### 🖼️ Dock Window Preview
- Hover over a Dock icon to automatically display previews of that app's windows
- Hover over a preview item to see a large live preview
- Quickly preview window content without clicking

### ⚡ Customizable Shortcuts
- All shortcuts can be customized
- Supports modifying window switching and same‑app switching shortcuts
- Real‑time preview of shortcut configuration

### 🎨 Theme Customization
- Supports light, dark, and auto‑follow system theme
- Multiple interface themes available
- Perfectly adapts to macOS system appearance

### 📐 Smart Layout
- Panel size automatically adapts to the number of windows
- Preview window size matches the actual window size
- Supports multiple displays and different resolutions
